# Business Context

Source: `raw/Fullstack_Task_Frontend_Focused_Updated_1.pdf` ("Doctor Tracker – Project Specification").

## What it is

A secure administrative web application where authenticated users manage doctors and the patients under them. Emphasis on performance, clean UX and data visualization.

## Nature of the engagement

Fullstack, frontend-focused delivery. The brief names these quality criteria:

- Code structure and cleanliness
- Query optimization
- UX/UI quality
- Data visualization implementation
- Performance efficiency
- Authentication implementation
- Best practices in Next.js and MongoDB
- Scalability considerations

Submission: project link and GitHub repo, with credentials if required.

## Users

- **Admin / authenticated user** — the only role described. Nothing is accessible unauthenticated.

## Deliverables

1. Working application (frontend, backend, MongoDB)
2. `README.md` in the standardized template: Description (elevator pitch), Setup Guide (with `.env.example`), System Architecture (data flow), Technical Decisions (deep dive on 2), Visual Evidence (desktop + mobile screenshots)
3. Live project link and GitHub repository
